> **TL;DR**
>
> * **ALiBi（Press et al., 2021）**：不加任何位置 embedding，也不旋转 Q/K，只在注意力 logits 上加一个与距离成正比的**负**偏置：$$s_{mn} = \boldsymbol{q}_m\cdot\boldsymbol{k}_n/\sqrt{d} - s_h\cdot\vertm-n\vert$$，每个头的斜率 $$s_h$$ 几何递减。一个"距离越远越不关注"的硬先验，就能让 1k 上下文训练的模型在 **16k** 推理时保持检索能力——**零参数、零训练改动、天生可外推**。
> * **为什么能外推**：偏置对任意 $$\vertm-n\vert$$ 都有良好定义且**单调递减**，不存在"训练长度外的相位组合"这种病——RoPE 的病根（[04 篇](/2026/08/29/posem-04-extrapolation-pi-ntk/)的频率外推）在 ALiBi 里根本没有对应物。外推时唯一的漂移来自 softmax 分母变大（熵膨胀），而 ALiBi 的线性远距惩罚恰好持续压低远端 logits，对冲了摊薄。
> * **代价与裁决**：ALiBi 的表达力弱于 RoPE（位置信息只是一个与内容无关的标量减法，没有 RoPE 的逐维频率调制），同长度训练时通常略逊于 RoPE；它还与 FlashAttention 的 softmax 结构需要额外 bias 广播。所以现实的市场划分是：**RoPE + YaRN/LongRoPE 占据主流（表达力上限高），ALiBi 及其思想活在各类"注意力局部性正则"和推理端 tricks 里**（如 attention sink 的线性近似、滑动窗口注意力的偏置形式）。MPT、BLOOM 采用了它，Falcon 部分变体也用过。
> 
> *系列至此有了完整的对称结构：RoPE 是"乘性、逐维、可外推但难"，ALiBi 是"加性、逐头、天生外推但粗"。*

## 1. 动机：能不能一开始就不需要外推手术？

[04](/2026/08/29/posem-04-extrapolation-pi-ntk/)/[05](/2026/08/29/posem-05-yarn-longrope/) 两篇的全部努力，都是在 RoPE 已经定型之后"打补丁"。ALiBi 的出发点不同：**回到设计桌前，选一个定义域天然覆盖任意长度的位置机制**。

候选其实不多：任何"位置参数化"（embedding 表、固定频率谱）都隐含训练分布；而**距离的解析函数**——比如 $$-c\vertm-n\vert$$——对任意距离都有定义。问题只剩：这样的硬编码先验会不会限制表达力？ALiBi 的实验回答：在 1.3B 规模、同长度评测下不掉点，外推时完胜。

## 2. 定义

### 2.1 公式

$$
s_{mn} = \frac{\boldsymbol{q}_m \cdot \boldsymbol{k}_n}{\sqrt{d}} - s_h \cdot (m - n), \qquad m \ge n \;(\text{causal})
$$

- 没有 $$\boldsymbol{p}_m$$，没有旋转，输入就是纯 token embedding；
- $$s_h$$ 是**第 $$h$$ 个头**的斜率，只惩罚、不加权（值恒负）。

### 2.2 斜率：一个漂亮的几何级数

对 $$n$$ 个头，起点 $$2^{-8/n}$$，公比相同：

$$
s_h = 2^{-8h/n} \cdot 2^{-8/n}\; \text{（实现上等价于 } \text{geomspace}(2^{-8/n},\, 2^{-8},\, n)\text{)}
$$

直觉：多头注意力的每个头本应分工，ALiBi 直接**把"观察半径"硬编码进头**——第一个头斜率大（如 8 头时 $$s_0 = 2^{-1} = 0.5$$，距离 4 就罚掉 2 分 logits，只看近处），最后一个头斜率 $$2^{-8} \approx 0.004$$（距离 512 才罚掉 2 分，看得很远）。头间按几何级数铺开，等于给模型一组现成的、不同焦距的镜头。

```python
import torch

def alibi_bias(n_heads: int, L: int, device="cpu"):
    # 斜率：几何级数，从 2^{-8/n} 到 2^{-8}
    slopes = torch.tensor(
        [2 ** (-8 * (h + 1) / n_heads) for h in range(n_heads)], device=device)
    m = torch.arange(1, L + 1, device=device).unsqueeze(1)   # query 位置（1 起）
    n = torch.arange(1, L + 1, device=device).unsqueeze(0)   # key 位置
    bias = -slopes.view(-1, 1, 1) * (m - n).clamp(min=0)     # (H, L, L)
    return bias
```

| 符号 | 变量 | Shape | 说明 |
|---:|---|:---:|---|
| $$s_h$$ | `slopes` | (H,) | 每头斜率，几何递减 |
| $$m-n$$ | `m - n` | (L, L) | 相对距离（causal 截负） |
| $$-s_h(m-n)$$ | `bias` | (H, L, L) | 加到 logits 上的偏置 |

与 [02 篇](/2026/08/29/posem-02-relative-t5/)T5 bias 的对比一目了然：T5 的 $$b_{c(\delta)}$$ **可学习但有 bucket 上限**；ALiBi 的 $$-s_h\delta$$ **不可学习但全域有定义**。一个是容量换外推，一个是外推换容量——位置编码设计的基本权衡在两篇论文之间形成了教科书级的对照。

## 3. 为什么天生可外推

三个原因，层层递进：

1. **定义域全覆盖**。$$-s_h(m-n)$$ 对 $$m-n = 10^6$$ 依然给出 $$-10^6 s_h$$：远端 key 的 logits 被压到负无穷附近，softmax 权重趋零。模型"处理超远距离"的方式是干脆不看它——这本身就是一个合理的长度外推策略（对比 RoPE：远端相位错乱后打分是**随机的**，softmax 会以不可控的概率给远端发权重）；
2. **单调性先验与语言局部性对齐**。归纳偏置"近处的信息更相关"在自然语言里大体成立（[03 篇](/2026/08/29/posem-03-rope/)提到 RoPE 的远程衰减也来自频率错拍，但那是震荡衰减；ALiBi 是严格单调）；
3. **对抗熵膨胀**。[05 篇](/2026/08/29/posem-05-yarn-longrope/)说长上下文的第一杀手是 softmax 摊薄。ALiBi 的偏置随长度增长持续变大（距离均值变远 ⇒ 平均惩罚变重），有效 logits 的动态范围被撑开，一定程度上自动完成了 YaRN 手工温度 $$t$$ 做的事——**ALiBi 是自带温度补偿的外推器**。

## 4. 弱点与后续演化

### 4.1 表达力天花板

位置信息只有"每头一个斜率 × 距离"这么一个标量通道：无法表达周期性、无法区分"距离 3 在句首 vs 句中"、无法做 [07 篇](/2026/08/29/posem-07-mrope-multimodal/)要讲的二维/三维坐标。经验上，同长度对比 RoPE 通常差一点点（早期论文显示 ALiBi 同长度持平或略好，是在 RoPE 尚未配合长上下文调优的年代；现代大模型的共识是 RoPE 上限更高）。外推的"便宜"终究是用先验的"硬"换的。

### 4.2 工程摩擦

- logits 加 (H, L, L) 偏置与 FlashAttention 的 fused kernel 不天然兼容（FlashAttention 起初不支持任意 bias；后续版本加入了 ALiBi 专用路径，但通用 bias 长期是痛点）；
- 每头不同斜率意味着头维不再是可自由置换的对称结构，对张量并行的头切分略有约束（小问题，但存在）。

### 4.3 家族变体

- **MPT / BLOOM**：直接采用（BLOOM 176B 是 ALiBi 最著名的落地）；
- **Giraffe（Fu et al., 2023）**：回到 RoPE 阵营但吸收 ALiBi 教训——**截掉部分高频维**（部分旋转 partial RoPE）+ 对其余维做插值，发现"删掉最不需要的高频"比"全体插值"更优。它的分析与 [04 篇](/2026/08/29/posem-04-extrapolation-pi-ntk/)的逐维诊断一致；
- **注意力 sink / 滑动窗口**（[05 篇](/2026/08/29/posem-05-yarn-longrope/)已述）：把"远处不重要"从偏置函数变成了显式的窗口结构——思想同源（局部性 + 少量全局通道），形态从连续偏置变成了离散拓扑。

## 5. RoPE vs ALiBi：一张终局对照表

| 维度 | RoPE | ALiBi |
|---|---|---|
| 形式 | 乘性旋转 Q/K，逐维多频率 | 加性负偏置，逐头单斜率 |
| 参数量 | 0 | 0 |
| 表达力 | 高（多分辨率、可扩到多维） | 低（单调距离先验） |
| 天生外推 | ✗（需 PI/NTK/YaRN 手术） | ✓（1k→16k 免疫） |
| 熵膨胀自补偿 | ✗（需 YaRN 温度） | 部分 ✓（线性远罚） |
| FlashAttention | 原生兼容（旋转在 Q/K 上） | 需 bias 支持（现已支持） |
| 多维扩展 | ✓（M-RoPE，[07 篇](/2026/08/29/posem-07-mrope-multimodal/)） | 不自然 |
| 代表模型 | LLaMA / Qwen / DeepSeek / Mistral | BLOOM / MPT |

1. 用 `alibi_bias` 实现 8 头 bias，画 (H, L, L) 的热力图切片——预期看到各头"焦距"按几何级数排开（第 1 头只在±50 内有显著权重，第 8 头在±2000 仍有非零权重）；再取 L=16384 检查数值范围，思考 FP16 下 $$-0.5\times16384=-8192$$ 已超安全 logits 范围时 softmax 如何靠平移不变性拯救数值稳定性；
2. 复现 ALiBi 论文的"外推对比"最小版：训练两个 2 层小模型（一个 RoPE、一个 ALiBi）各 512 长度，在一个需要远程检索的合成任务（答案藏在第 $$L-k$$ 个位置）上测 L=1024/2048/4096 的准确率曲线——预期 RoPE 在 L=1024 时准确率从 95% 骤降至 60%，ALiBi 仍保持 85% 以上，看两条曲线的分岔点。
