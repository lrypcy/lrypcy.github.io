<h2 id="cat-world-model">世界模型</h2>

### Bind-WAM：每个重规划步都想象未来太贵，该先问「现在需不需要想象」

`值得读 ★★★★☆` ｜ `影响力 ★★★★☆`

**来源**：[arXiv:2611.15368](https://arxiv.org/abs/2611.15368)

世界动作模型（WAM）联合预测未来视觉状态与动作能改善机器人学习，但**在每个重规划步都生成一个视觉未来既昂贵、有时又没必要**。于是引出一个关键问题：机器人策略该在什么时候想象未来？

Bind-WAM 的答案是用**语言–物体绑定不确定性**来决定：当当前观测不足以支撑稳定的、任务相关的动作生成时，才选择性地调用联合未来–动作生成。做法是先用离线标注流水线，借完整示范与动作上下文识别任务相关物体，并检出三类问题——参考不匹配、不可见、身份漂移；这些伪标签去监督一个轻量 router，由它从当前观测与语言指令预测绑定不确定性。推理时，共享的 WAM 策略按预测出的不确定性、以及它在相邻重规划步之间的变化，来决定是否触发选择性未来想象。

作者把「绑定不确定性」确立为一个强且可解释的信号——这比「每步都想象」更接近一个可用的计算预算分配准则。

### BWM-Forge：让 coding agent 写 Blender 场景程序，生成可控机器人视频

`值得读 ★★★☆☆` ｜ `影响力 ★★★☆☆`

**来源**：[arXiv:2611.16221](https://arxiv.org/abs/2611.16221)

生成多样的机器人视频需要控制场景几何、机器人运动与视角。端到端视频生成对这些变量缺少直接通路，导致针对性编辑与跨任务复用都很难。BWM-Forge 是代码驱动的框架：给定机器人资产与任务描述，输入初始图像、带运动数据的图像或人类示范视频，一个 coding agent 就构造出**可编辑的 Blender 场景程序**，指定物体、机器人运动与相机；生成的代理视频为视频生成模型提供结构与运动参考，后者再补上视觉细节。一个多 agent harness 协调输入处理、场景构建、评审与渲染，自动评测与用户反馈支持迭代精修，经验库存储与检索可复用的建模与渲染规则。

这套设计支持多种机器人本体、同步视角与外观变化共享同一场景程序。在覆盖 5 种机器人的 15 个任务上，与 LingBot-World Base Cam 相比，BWM-Forge 在美学质量、成像质量、主体与背景一致性、运动平滑度、以及 RoboJudge-9B 的物理遵循与指令对齐分数上都更高（基线仅在动态度上更高）。

<h2 id="cat-embodied">具身智能</h2>

### SALA：潜动作按「语义对应」对齐，人类与机器人数据就能双轴扩展

`值得读 ★★★★☆` ｜ `影响力 ★★★★☆`

**来源**：[arXiv:2611.17110](https://arxiv.org/abs/2611.17110)

具身基座模型依赖多样的机器人交互数据，而采集昂贵。第一人称人类视频是互补的经验来源，潜动作模型（LAM）是常用手段。相比 WAM，LAM 避免策略学习与执行中的显式像素预测，训练更省、推理可能更便宜。但多数 LAM 只靠视频重建学潜动作，表征会**按视觉外观聚类而不是按底层动作聚类**，于是人类动作与机器人对应动作对不齐。

SALA 强调为潜动作建立语义对应：**不需配对数据**，用无配对人类片段与机器人片段的语言描述估计语义相似度，监督跨本体对应；再把这些相似度转成软邻域结构，把人类潜动作拉向语义相关的机器人潜动作，同时用机器人动作重建把潜空间锚在控制上。得到的共享潜动作空间，为在人类与机器人视频上训练具身基座提供统一监督。

值得注意的是它的两条扩展轴：① 用越来越多**通用人类视频预训练**，下游机器人动作预测误差持续下降；② 用越来越多**任务特定人类视频后训练**，真实机器人任务成功率显著提升。这给「人类视频到底能带来多少增量」提供了一个可测的答案。

### H2E：把调用 VLA 的 Agent 的经验，蒸馏回 VLA 自己

`值得读 ★★★★☆` ｜ `影响力 ★★★☆☆`

**来源**：[arXiv:2611.16246](https://arxiv.org/abs/2611.16246)

导航 agent 用 LLM 规划器去调用 VLA，每个 episode 都要过 LLM，带来成本与延迟。常见做法是蒸馏规划器，但 H2E 选择**把成功的 agent 经验蒸馏进 VLA**，让 VLA 在测试时独自导航。

难点在于 agent 会话不是 VLA 示范：里面混着规划工具驱动的动作、子指令与绕路。H2E 把它们转成 VLA 训练数据——每个动作都变成原始任务指令下的一个 VLA 动作，以得到的位姿为目标；对远离目标的步**屏蔽损失**；把距离目标 1 米内的每个访问状态标为 stop。再用低秩适配更新 VLA。结果是 VLA 学会了在目标处停下、也能找到基座模型原本到不了的目标：在全部 3,189 个 REVERIE-CE val-unseen episode 上，把一个 8B VLA 的成功率从 **35.0% 提到 44.9%**。

<h2 id="cat-rl">强化学习与后训练</h2>

### OMA：多轮 GRPO 的记账偏差——同一次结局被算多次，不同轨迹的权重又不相等

`值得读 ★★★☆☆` ｜ `影响力 ★★★☆☆`

**来源**：[arXiv:2611.16816](https://arxiv.org/abs/2611.16816)

为了让长交互上下文可控，面向多轮 LLM agent 的逐步 group-relative 训练会把每条源轨迹物化成多个 response 行与有效 token。这种扩展带来一个**与轨迹内信用分配不同**的外层记账问题：基于行的结局统计可能把一次 episode 的结局**重复计数**；而 token 级归约又可能在不同轨迹间分到不等的总目标权重。作者称之为 outcome-statistics multiplicity 与 objective-mass imbalance。

OMA（Outcome-Mass Alignment）把这两个记账选择都显式化：Outcome Alignment 在**唯一的源轨迹**上计算结局统计，Mass Alignment 在轨迹内聚合优化器原生 token 目标后控制总目标权重。它不改动基础优化器的信用分配、重要性比或裁剪。在两组模型规模、匹配的 ALFWorld GRPO 对比中（失败轨迹通常比成功轨迹扩张得多得多），OMA 把匹配视界的端点成功率提升 **7.0–9.4 个百分点**；普通 WebShop 上效应较弱或出现反转。
