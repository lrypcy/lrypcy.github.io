<h2 id="cat-world-model">世界模型</h2>

### La-JEPA：JEPA 特征比视频 VAE latent 更适合当策略底座

`值得读 ★★★★★ ｜ 影响力 ★★★★☆`

**来源**：[arXiv:2611.08156](https://arxiv.org/abs/2611.08156)

世界动作模型去改造预训练视频生成器，VLA 走预训练视觉语言骨干——两条路线都把策略架构与推理成本绑在「为生成而不是为控制设计」的大 Transformer 上。这篇问的是：这些面向生成的选择，究竟对控制有多大影响？

La-JEPA（Latent Action JEPA）的做法是：策略 Transformer **从零训练，只在一个预训练的 V-JEPA 2.1 编码器的特征空间里学**。跟着 Fast-WAM 的思路，训练时联合预测未来特征与动作，推理时只生成动作。在**没有具身预训练**的策略里，它在 RoboTwin 2.0 的 clean 与 randomized 场景、以及指令修正后的 LIBERO-Plus 上都达到 SOTA，参数量远少于最强的对比策略，且在与 Fast-WAM 相当的性能下快很多；也超过了最接近的 JEPA 方法 LeapBot-WA 与 JEPA-WAM（它们带预训练策略骨干）。

设计研究给出两个直接可用的结论：**JEPA 特征优于视频 VAE latent，在分布外尤其明显**；而且训练时的未来预测选择会显著影响策略，哪怕推理时跳过了未来预测。论文还顺带指出并修正了 LIBERO-Plus 官方评测器在多数变体上损坏指令的问题，并重评了若干强开源基线。作者的判断是：机器人基座模型可能更需要为控制设计的架构，而非从生成任务继承来的架构。

### GuidedWAM：给冻结的世界动作模型在采样时注入驾驶目标

`值得读 ★★★☆☆ ｜ 影响力 ★★★☆☆`

**来源**：[arXiv:2611.07912](https://arxiv.org/abs/2611.07912)

自动驾驶的 WAM 把驾驶策略与视觉世界模型耦合在单个生成网络里，目标在训练后就固定了——要换一个新的驾驶目标就得重训。这篇研究「能量引导」作为一个通用机制：GuidedWAM 是一个模型无关的框架，在**采样时**把驾驶目标注入冻结的 WAM。

做法是把每个目标构造成采样器中间「干净动作估计」上的可微能量，只需要对冻结模型做前向访问，并用采样时的引导调度、逐能量归一化与速度有界修正来稳定。在 NAVSIM v2 hard-split 上，引导让三个公开的冻结 WAM 都提升 1.8–3.6 EPDMS（三次采样种子平均），每步采样时间只增加不到 10%。它把能量引导定位成 WAM 的一种实用的后训练控制通道。

### WAM-Sim0.1：用持久分层记忆压住驾驶世界模型的漂移

`值得读 ★★★☆☆ ｜ 影响力 ★★★☆☆`

**来源**：[arXiv:2611.07939](https://arxiv.org/abs/2611.07939)

自回归驾驶世界模型在长 rollout 上会系统性出现结构漂移、身份漂移与质量衰减，根因是瞬时条件信号缺持久状态。WAM-Sim 用一个**持久分层记忆**来锚定，并按三个时间/语义尺度组织上下文：位姿对齐的结构 token 编码持久道路拓扑、只读场景 token 提供带地理定位的背景外观、一次写入的实例 token 在遮挡与 chunk 边界间保留各交通参与者身份。为恢复被多尺度条件削弱的锐度与物理合理性，它引入在线后训练框架，用分层对齐的视觉奖励与一个 VLM 物理裁判引导、以 flow-matching RL 优化自生成 rollout。

nuScenes 上生成保真度 FID=3.47、FVD=25.72，下游感知 24.16 mAP、71.23 road mIoU。作者强调不变记忆把策略优化限制在锚定上下文内，有助于抑制语义坍缩与 reward hacking——这是把记忆当「约束」而不是「召回」的一个用例。

<h2 id="cat-embodied">具身智能</h2>

### SLA：把空间对齐从任务适配提前到持续预训练

`值得读 ★★★☆☆ ｜ 影响力 ★★★☆☆`

**来源**：[arXiv:2611.08373](https://arxiv.org/abs/2611.08373)

可靠的机器人操作既要语义理解，也要三维空间里的精确控制。但 VLA 底座大多继承 2D 视觉语言预训练的表征，空间监督往往只在任务特定适配阶段才引入。SLA（Spatial-Language-Action Model）把隐式空间对齐**扩展到持续预训练**，并在下游后训练中保持。

它从预训练的 pi05 策略初始化，联合优化动作预测与「中间视觉嵌入 ↔ 冻结 3D 感知模型空间表征」的对齐；为此整理了跨不同本体、任务、场景的异构机器人数据集，并引入 feature-dependent gates，从多个 VLA 层自适应聚合视觉嵌入做空间监督。教师进一步利用部分可得的深度与相机标定（配合 RGB），让异构几何标注都能用上；概率式状态丢弃则促使模型依赖视觉线索、缓解对示范轨迹的过拟合。所有辅助组件只在训练时用，推理架构不变，可直接复用预训练 VLA 权重。

### RoboARCade：agent 直接当机器人策略，GPT-6 Astra 也才 49.8%

`值得读 ★★★★☆ ｜ 影响力 ★★★☆☆`

**来源**：[arXiv:2611.08209](https://arxiv.org/abs/2611.08209)

多模态能力提升让 agent 能直接当机器人策略，作者称这一设定为 agentic robot control（ARC）。RoboARCade 是一个跨三种本体的长程操作 benchmark，用来测 in-context 适应、记忆与精确控制推理。任务建立在既有开源 benchmark 上，通过**放宽初始条件范围**把它们变难。工程上刻意做得好用易扩展：所有任务跑在单一仿真后端 MuJoCo 上，每个任务是自包含数据包，agent 通过可互换接口接入。

结果：**GPT-6 Astra 49.8%，Claude Fable 5.1 43.6%**，仍有相当大的提升空间。一个有意思的对照：更丰富的视觉接口在 1.7–2.3 倍成本下只多带来 1.5–6.8 个点。失败大多来自选错了操作策略、或好策略执行得不够精确，很少是因为误解场景；而且 agent 会错误地宣称成功。

<h2 id="cat-rl">强化学习与后训练</h2>

### AttnSR：用策略注意力反推步级奖励，ALFWorld 91.2% → 97.1%

`值得读 ★★★☆☆ ｜ 影响力 ★★★☆☆`

**来源**：[arXiv:2611.07932](https://arxiv.org/abs/2611.07932)

长程 LLM agent 做多步决策，但只有结果奖励的 RL 对单步几乎不给直接监督。AttnSR 是一种步级奖励增强方法：**从训练 replay 中抽取的策略注意力里推导奖励分配**，不需要单独训练奖励模型，也不需要额外 rollout。它沿策略模型的注意力图反向追溯，估计较早步骤与最终回答的相关性；终止步相对一个运行基线，决定这些奖励是强化还是惩罚被选中的步骤。

在受控的 Qwen2.5-7B-Instruct 研究里，AttnSR 在 ALFWorld 所有评测 checkpoint 上都优于 PPO 基线，最终 held-out 成功率从 91.2% 提升到 97.1%。消融显示收益取决于中间奖励**怎么分配**，而不是简单把步奖励按时间累加。在 ScienceWorld 上每个 checkpoint 都有改善，同时减少 29.9% 的环境交互。
