# 07 · 潜空间与 JEPA 路线（D6）

> **核心问题**：规划需要的是像素级未来，还是"控制相关"的未来？
> 如果是后者，就没必要生成视频——在潜空间做预测可以把规划成本压一到两个数量级。
> 本篇给出这个取舍的定量刻画，并解析 JEPA 路线为什么必须改造才能用于 WAM。

---

## 1. 像素预测的三重浪费

在像素（或视频 latent）空间做规划，付出三份代价：

1. **计算浪费**：注意力代价 $\propto N_{\text{token}}^2$，而 $N_{\text{token}}$ 里绝大部分是纹理/光照 token。
2. **信噪比浪费**：未来帧里不可预测的部分（光照抖动、背景、不可控物体）成为预测目标的噪声，稀释了学习信号。
3. **规划浪费**：打分器 $J(\hat{o}')$ 必须从高维观测里提取"任务有没有进展"，这是额外的解耦任务。

形式化地，把观测分解为控制相关部分与控制无关部分：

$$o = \underbrace{c(s)}_{\text{控制相关}} + \underbrace{\xi}_{\text{纹理/光照/背景}}$$

预测未来的最优误差：

$$\min_f \mathbb{E}\|f(o,a) - o'\|^2 = \underbrace{\mathbb{E}\|\xi' - \xi\|^2}_{\text{不可约，且很大}} + \mathbb{E}\big[\mathrm{Var}(c(s') \mid o, a)\big]$$

第一项占了预算的绝大部分，但**对规划毫无贡献**。

## 2. JEPA 的数学

### 2.1 基本形式

JEPA（Joint Embedding Predictive Architecture）不在数据空间做重建，而在**表征空间做预测**：

$$\mathcal{L} = \big\|\, P_\phi\big(\mathrm{Enc}_\theta(x_{\text{vis}}),\, \text{pos}\big) - \mathrm{sg}\big(\mathrm{Enc}_{\bar\theta}(x_{\text{mask}})\big)\,\big\|^2$$

三个关键设计：

- **$\mathrm{sg}$（stop-gradient）**：目标侧不回传梯度
- **$\bar\theta$（EMA 目标编码器）**：$\bar\theta \leftarrow \tau \bar\theta + (1-\tau)\theta$
- **非对称的 predictor $P_\phi$**：只加在在线分支

### 2.2 为什么必须非对称

**命题（塌缩）**：若去掉 $\mathrm{sg}$、$P_\phi$、$\bar\theta$ 中的任何一个，$\mathrm{Enc}$ 退化为常数映射是一个全局最优解（损失为 0）。

理由：若两端都用同一个 $\mathrm{Enc}$ 且都回传梯度，则 $\mathrm{Enc} \equiv c$（常数）时，两端输出恒等，损失为 0。

**非对称如何阻断塌缩**：目标由 $\bar\theta$ 产生且不回传梯度，在线分支必须"追"一个**外部给定的、缓慢变化的**目标。若在线编码器塌缩，目标不会跟着塌缩（EMA 有滞后），损失立刻变大。

这是 BYOL / SimSiam / JEPA 家族的共同机制，也是 **SG-WAM 的 EMA 目标**采用同一技巧的原因（§5）。

### 2.3 塌缩的残余风险与对策

EMA 只是**延迟**了塌缩，不保证避免。实践中还需要：

| 对策 | 数学形式 | 作用 |
|:---|:---|:---|
| 方差正则（VICReg 式） | $\max(0, \gamma - \mathrm{std}(z))$ 的 hinge 损失 | 强制每维标准差不低于阈值 |
| 去相关（Barlow Twins 式） | $\|\mathrm{Corr}(z) - I\|_F^2$ | 防止各维塌到同一方向 |
| 停止梯度的 predictor | $P_\phi$ 只在线侧 | 让编码器不能"作弊" |
| 归一化 + 白化 | — | 稳定训练 |

## 3. V-JEPA 为什么不能直接当 WAM

[WA-JEPA (2608.20974)](https://arxiv.org/abs/2608.20974) 明确指出 V-JEPA 的两个结构性缺陷：

### 3.1 随机掩码 ≠ 预测未来

V-JEPA 的训练任务是**随机时空掩码补全**：

$$\text{随机遮掉一些 patch} \to \text{从可见 patch 预测被遮的 patch}$$

这是一个 **"填洞"（inpainting）** 任务，不是 **"外推"（extrapolation）** 任务。填洞可以靠周围帧的时空平滑性解决，不需要理解动力学。

对规划而言这是错的归纳偏置：规划需要的是 **future-directed** 预测。

### 3.2 确定性回归 → 平均化

V-JEPA 用 MSE 回归潜表示。与 01 §4.1 同理，学到的预测器输出的是

$$\hat{z}' = \mathbb{E}[z' \mid z]$$

**后验均值**。在真实世界（未来本质是多模态的）这会把预测拉到多个可能未来的平均——一个物理上不存在的状态。这正是 Lab D3 展示的机制（在潜空间版本）。

## 4. WA-JEPA：三个针对性改造

[WA-JEPA](https://arxiv.org/abs/2608.20974) 是对 V-JEPA 的"WAM 化"，三个改造一一对应上面的缺陷：

### 改造 ①：混合未来掩码预训练（hybrid future-masked pre-training）

把随机掩码换成**未来掩码**：遮掉的是**时间上靠后的**整个片段，模型必须从历史上下文外推。

$$\mathcal{L}_{\text{mask}} = \big\|P(\mathrm{Enc}(x_{\le t})) - \mathrm{sg}(\mathrm{Enc}_{\bar\theta}(x_{> t}))\big\|^2$$

"混合"指的是保留一部分随机掩码（保留表征学习的多样性），同时加入未来掩码（引入 future-directed 偏置）。

### 改造 ②：潜空间条件流匹配（conditional flow matching over latent futures）

把确定性回归换成**生成式**预测：

$$\mathcal{L}_{\text{CFM}} = \mathbb{E}_{t, z_0, z_1}\big\|v_\theta(z_t, t, c) - (z_1 - z_0)\big\|^2, \quad z_t = (1-t)z_0 + t z_1$$

其中 $z_1$ 是未来的潜表示，$c$ 是历史上下文（**注意：这里还不条件于动作**，动作在改造 ③ 引入）。

这一步的数学意义：**把潜空间预测从"点估计"变成"分布估计"**，从而能表达多模态未来。这与 D3 §1.2 的结论一致——多峰问题上，点估计必然失败。

### 改造 ③：联合未来-动作预测器（joint future-action predictor）

在同一个时空潜空间里**一起去噪**未来场景 token 与自车轨迹：

$$y = [z^{\text{scene}}_{t+1:t+H};\ a_{t:t+H}], \quad \mathcal{L} = \mathbb{E}\|v_\theta(y_\tau, \tau, c) - (y_1 - y_0)\|^2$$

**关键作用**：动作监督直接塑造世界表征。数学上这是因为梯度可以从动作损失流向场景 token 的表征：

$$\frac{\partial \mathcal{L}_{\text{action}}}{\partial \theta_{\text{enc}}} \ne 0$$

这正是 01 §2.2 判定边界第 ③ 条——"未来训练动作通路"。它保证了学到的潜空间是 **action-relevant** 的，而不是通用的语义表征。

### 4.1 实测

| 基准 | 指标 | 值 |
|:---|:---|:---|
| NAVSIM-v2 | EPDMS | **91.7**（超过最强端到端 +1.6、最强 WAM +1.3） |
| HUGSIM（闭环，未做 HUGSIM 特化微调） | HD-Score | **0.4462**（同协议下最佳） |

预训练用 nuPlan 视频，微调用 NAVSIM。

## 5. SG-WAM：自引导世界建模

[SG-WAM (2608.01397)](https://arxiv.org/abs/2608.01397) 从另一个角度解决同一个问题，且**只有 0.9B 参数、无大规模具身预训练**就做到 LIBERO 98.5% / LIBERO-Plus 73%。

### 5.1 三个组件

**（a）可学习的 dynamics tokens**

在策略骨干的 token 序列里插入一组可学习的 token $D = [d_1, \dots, d_m]$，专门用于承载动力学信息。

**（b）自引导世界预测器（Self-Guided World Predictor, SGWP）**

$$\hat{d}_{t+H} = \mathrm{SGWP}\big(d_t,\ a_{t:t+H-1}\big)$$

预测目标是 **同一个策略骨干的 EMA 副本**在真实未来帧上的输出：

$$d^{\text{target}}_{t+H} = \mathrm{sg}\Big(\mathrm{Backbone}_{\bar\theta}\big(o_{t+H}\big)[D]\Big)$$

**这就是 §2.2 的 EMA + stop-grad 机制**，只是用在"预测未来"而不是"表征学习"上。它解决的是：预测目标必须在**策略自己使用的表征族**里，否则学到的动力学和策略是两套语言。

**（c）几何监督**

对策略的图像 token 表征施加几何约束（深度/位姿/对应关系），让 $D$ token 有空间接地的上下文。

### 5.2 联合目标

$$\mathcal{L} = \underbrace{\mathcal{L}_{\text{action}}}_{\text{flow matching 动作}} + \lambda_1 \underbrace{\mathcal{L}_{\text{latent future}}}_{\text{SGWP}} + \lambda_2 \underbrace{\mathcal{L}_{\text{geom}}}_{\text{几何}}$$

三个损失端到端联合优化。**注意这里没有像素重建损失**——完全在表征空间做世界建模。

### 5.3 为什么 0.9B 就够

对比之下，基于像素的 WAM 需要 2B–14B 的视频骨干。SG-WAM 的解释是：**大部分参数被用来建模纹理，而纹理对控制无用**。把这部分参数省下来，0.9B 就够了。

这与 §1 的三重浪费是一致的。

## 6. Lab D6：潜空间维度的取舍

设置：观测 $o \in \mathbb{R}^{62} = \underbrace{\mathbb{R}^6}_{\text{真状态}} + \underbrace{\mathbb{R}^{56}}_{\text{每步 i.i.d. 的纹理噪声}(\sigma=0.6)}$。用 PCA（只用观测数据，无额外监督）把 $o$ 降到 $k$ 维，在潜空间拟合线性动力学 $\hat{z}' = \hat{A}z + \hat{B}a$，然后用闭式最小二乘做 $H=10$ 步规划（目标是**可达的**，所以最优回报 = 0）。规划出的动作序列在**真动力学**上执行并计分。

```
== Lab D6: 潜空间维度 k 的规划质量 (目标可达, 最优回报 = 0) ==
  观测 62 维 = 6 维真状态 + 56 维不可预测纹理(σ=0.6); H=10
  基线 '什么都不做' = -10.77   Oracle(真动力学+真状态) = -0.00

     k      最优λ        真实回报    距 Oracle      维度代价 k^2
  ----------------------------------------------------------
     3  1.0e-01      -1.653      -1.653             9
     4  1.0e-01      -2.163      -2.163            16
     6  1.0e-04      -0.000      -0.000            36
     8  1.0e-06      -0.000      -0.000            64
    12  1.0e-06      -0.000      -0.000           144
    20  1.0e-06      -0.000      -0.000           400
    40  1.0e-06      -0.000      -0.000          1600
    62  1.0e-06      -0.000      -0.000          3844
```

三条结论：

1. **$k$ 有硬下界，由控制相关信息量决定**。$k=3, 4$（小于真状态维 6）时规划明显退化（-1.65、-2.16），$k \ge 6$ 立刻达到最优。丢掉控制相关维度的代价是**断崖式**的，不是平滑的。

2. **$k$ 没有上界收益**。$k$ 从 6 涨到 62（多了 56 维纯噪声），规划质量**完全不变**（都是 -0.000）。也就是说多出来的维度对规划零贡献，却把维度代价从 36 拉到 3844——**107 倍**。

3. 因此最优策略是：**把潜空间压到刚好覆盖控制相关子空间**。这就是 JEPA / latent WAM 的全部论点，而 Lab D6 给出了它的定量形态：收益曲线是**阶跃的**（够用就行），成本曲线是**平方的**。

> **诚实标注**：本实验在**充足数据**（40000 样本）下，线性模型能自动忽略噪声维度，所以高维模型没有显式变差。真实收益还包括**样本效率**——数据有限时高维模型会过拟合。这一点我在 toy 上没有拿到稳定的数值结论，作为定性判断列出。机器人数据稀缺是常态，因此样本效率那一半收益只会更大。

## 7. 潜空间路线的风险

| 风险 | 描述 | 缓解 |
|:---|:---|:---|
| **表征塌缩** | 潜预测退化为常数 | EMA + stop-grad + 方差/去相关正则（§2.3） |
| **潜空间里无法定义"物理正确"** | 像素模型至少肉眼可判 | 只能用下游任务指标；需要几何监督（SG-WAM） |
| **丢失罕见但关键的信息** | 压缩过猛丢掉接触/力 | 显式几何通道（JOPAT 的点追踪 + 可见性） |
| **与视频基座不兼容** | 放弃预训练权重 | 需要重新预训练（WA-JEPA 在 nuPlan 上重训） |

最后一条是最大的实际障碍：**潜空间路线放弃了视频预训练的红利**。这也是为什么它目前主要在自动驾驶（有大量 nuPlan/NAVSIM 视频）而不是机械臂上取得成果。

## 8. 收敛度与未解决

**已收敛**：
- 潜空间预测必须是**生成式**（流匹配）而非确定性回归——多峰未来下点估计必然失败（§4.2）。
- EMA + stop-grad 是标准配置（JEPA 与 SG-WAM 殊途同归）。
- 动作监督必须能流回世界表征（§4.3）。

**未收敛**：
- **潜空间的"多少维够用"没有度量方法**。Lab D6 给了 toy 版本的答案（控制相关子空间的维数），但真实场景里怎么估计这个维数？没有工具。
- **潜空间缺少"物理正确性"的判据**，只能靠下游任务。
- **与视频基座的关系**：是替换还是级联？目前两派并行。

---

## 9. 要点

1. 像素规划付三份代价：计算、信噪比、规划（§1）。
2. JEPA 的**非对称**（EMA + stop-grad + predictor）是防塌缩的必要条件，不是可选技巧（§2.2）。
3. V-JEPA 不能直接当 WAM：随机掩码是填洞不是外推，确定性回归会平均化（§3）。
4. WA-JEPA 的三个改造：未来掩码、潜空间条件流匹配、联合未来-动作去噪（§4）。
5. SG-WAM 把 EMA 自监督用在策略自己的表征族上，0.9B 做到 LIBERO 98.5%（§5）。
6. **潜空间维度收益是阶跃的、成本是平方的**——压到控制相关子空间即可，多一维都不值（§6）。
