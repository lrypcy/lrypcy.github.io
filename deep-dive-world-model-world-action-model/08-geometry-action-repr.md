# 08 · 几何感知与动作表征（D7）

> **核心问题**：能不能学一个**本体无关**的世界动力学模型？
> 如果能，机器人策略的成本就从"每个平台一个数据采集项目"降到"一个下午的遥操作"。
> 本篇给出跨本体迁移的形式化，并用 Lab D7 量化：**共享动作接口到底省了多少样本，代价是什么**。

---

## 1. 跨本体迁移的形式化

### 1.1 设定

本体 $e$ 有动作空间 $\mathcal{A}_e$（Franka 是 7 维关节，人形手是 20+ 维，人手用 MANO 参数化）。世界动力学**本体无关**：

$$o' = g\big(o, \underbrace{u}_{\text{物理作用}}\big)$$

动作通过本体的运动学映射产生物理作用：

$$u = T_e(a_e), \quad T_e: \mathcal{A}_e \to \mathcal{U}$$

### 1.2 关键假设：映射已知 vs 需要学

- **latent action**：$T_e$ 是**学出来的** → 每个本体一个子空间，跨本体需要对齐，样本效率低（见 03 §3.2 的信息瓶颈分析）
- **骨架 / pointmap 渲染**：$T_e$ 是**已知的**（URDF/MANO 的正向运动学 + 投影 + 光栅化）→ **零样本可用**

这就是 OSCAR 的核心论点：**渲染函数是已知的物理知识，不该让模型去学。**

### 1.3 本体无关同态

形式化地，理想的动作表征应是一个同态：

$$\mathcal{R}: (\mathcal{M}_e,\ a_e) \mapsto s \in \mathbb{R}^{H \times W \times 3}, \quad \forall e \in \mathcal{E}$$

满足：
1. **格式统一**：所有本体输出同一 shape
2. **空间对齐**：与观测在同一坐标系
3. **充分性**：$\mathcal{R}(a_e)$ 决定了物理作用（不丢控制信息）
4. **本体无关**：$\mathcal{R}$ 不依赖具体本体的外观

骨架渲染满足 1、2、4，对 3 部分满足（表达不了接触力、形变、摩擦）。

## 3. 理论：共享动力学何时可行、代价是什么

假设真实动力学含**本体特定残余**：

$$o' = C o + D\,T_e(a_e) + \kappa\, E_e a_e + \xi$$

第二项通过共享接口 $u$ 作用，第三项是接口表达不了的部分（接触力分布、连杆柔性、特定的抓取方式）。

**两个误差源**：

1. **估计误差**：从有限数据学 $C, D$ 的误差 —— 共享数据（多本体）**能大幅降低**
2. **接口损失**：$\kappa E_e a_e$ 无法用 $u$ 表达 —— **共享解决不了**，只能靠目标本体的数据补

**关键推论**：共享动作接口把样本复杂度的主要部分（学世界动力学）摊到所有本体上，只留下一个**小的本体特定残差**需要目标数据去补。这正是 [MotuBrain](https://arxiv.org/abs/2604.27792) 报告"50–100 条轨迹适配新人形"的机制。

## 4. Lab D7：样本复杂度实测

设置：观测 $o \in \mathbb{R}^{20}$，通用物理作用 $u \in \mathbb{R}^3$。本体 1 动作 $\mathbb{R}^7$、本体 2 动作 $\mathbb{R}^6$，映射 $M_1, M_2$ **已知**。动力学：

$$o' = C o + D\,u + 0.35 \cdot E_e a_e + \xi$$

源本体（本体 1）有 20000 条数据，目标本体（本体 2）只有 $n$ 条。三种做法：

- **A 从零学**：在目标本体的 $n$ 条上直接拟合 $[o, a_2] \to o'$（520 个参数）
- **B 只调接口空间**：源数据学出 $\hat{C}, \hat{D}$，目标本体只学 $u$ 空间的修正（18 个参数）
- **C 预训练 + 残差微调**：源数据学出 $\hat{C}, \hat{D}$，目标本体学完整残差（120 个参数）

```
  零样本(只靠已知接口 M2, 不用任何目标本体数据) 误差 = 2.283

          目标本体样本 n           A: 从零学(520参数)              B: 共享接口+残差(18参数)
  ------------------------------------------------------------------------
                10                 190.483                         2.053
                20                  43.088                         2.035
                50                   0.391                         2.009
               100                   0.271                         2.006
               300                   0.218                         2.004
              1000                   0.204                         2.004
              5000                   0.200                         2.004
             20000                   0.200                         2.004

  补一个实用配方 C: 共享接口预训练 + 目标本体残差微调
          目标本体样本 n          A: 从零学        B: 只调 u 空间(18)          C: 预训练+残差微调(120)
  ----------------------------------------------------------------------------------
                10         233.100                 2.038                     0.427
                20         118.193                 2.012                     0.266
                50           0.475                 2.007                     0.224
               100           0.276                 2.007                     0.212
               300           0.218                 2.005                     0.205
              1000           0.204                 2.004                     0.202
              5000           0.200                 2.004                     0.200
```

### 4.1 四条结论

**① 共享接口的价值在小样本区，且是数量级的。** $n=10$ 时：A 的误差是 **233**，B 是 **2.04**，C 是 **0.427**。差 **500 倍**。

**② 接口损失是真实存在的天花板。** B 的误差**永远停在 2.004**——无论给多少目标数据。因为 $u \in \mathbb{R}^3$ 表达不了 $\mathbb{R}^6 \to \mathbb{R}^{20}$ 的本体特定残余。**共享接口不是免费的**：它省了样本，但限制了你最终能有多准。

**③ 正确配方是 C：共享接口预训练 + 目标本体残差微调。** C 在所有 $n$ 上都最好，而且 $n=10$ 就已经达到 0.427（A 要 $n \ge 50$ 才到 0.475，B 永远到不了）。

这解释了 MotuBrain 的"50–100 条轨迹"：不是零样本，而是**用一个好的初始化把样本需求从 $10^3$–$10^4$ 压到 $10^2$**。

**④ 交叉点在 $n \approx 30$–$40$。** 超过之后从零学也能追上（因为 520 个参数在 $n>300$ 时已经够拟合）。所以：**目标本体数据充足时，共享接口的收益会被接口损失抵消**。共享接口的价值与"目标本体数据稀缺程度"成正比。

### 4.2 实用判据

| 目标本体数据量 | 建议 |
|:---|:---|
| $< 50$ 条 | **必须**用共享接口 + 残差微调（配方 C） |
| $50$–$500$ 条 | 共享接口预训练仍明显更好 |
| $> 10^3$ 条 | 收益变小；但要检查接口损失是否成为天花板 |

## 5. OSCAR：骨架渲染（深化）

已在 03 §4 讲过渲染管线，这里补充跨本体层面的数学。

### 5.1 为什么骨架是"已知映射"

正向运动学（POE 公式）：

$${}^0T_i(q) = \prod_{k \le i} e^{\hat{\xi}_k q_k} \cdot {}^0T_i(0)$$

这是**解析的、可微的、零参数的**。给定 URDF 就能算，不需要数据。

对比 latent action：$T_e$ 需要从数据里学，而机器人数据稀少。**能用物理知识算出来的，就不要学**——这是 OSCAR 最本质的方法论贡献。

### 5.2 为什么人手和夹爪能统一

把 URDF 换成 MANO 手模型，渲染函数的形式不变：

$$\mathcal{R}_{\text{URDF}}(\mathcal{M}_{\text{arm}}, q) \equiv \mathcal{R}_{\text{MANO}}(\mathcal{M}_{\text{hand}}, \theta)$$

输出都是 $H \times W \times 3$ 的骨架图。**五指手和两指夹爪共享同一个条件格式**——这在 latent action 里是不可能的（两者的嵌入在不同子空间）。

### 5.3 实测

OSCAR 覆盖 4 种机器人本体 + 人手数据，在 Cosmos-Predict2.5-2B 上单卡 GH200 微调，PSNR 24.24 / SSIM 0.846 / LPIPS 0.094 / FVD 7.08，跨本体排序 Spearman 0.750 / Pearson 0.852。

## 6. 几何感知：不只是动作表征

"几何"在这个方向里还有第二层含义：**让模型知道东西在哪里、怎么接触的**。

| 技术 | 做什么 | 代表 |
|:---|:---|:---|
| **几何监督** | 对策略的图像 token 表征施加深度/位姿约束 | [SG-WAM](https://arxiv.org/abs/2608.01397) |
| **点追踪 + 可见性** | 联合去噪时加入 2D 点轨迹与可见性通道，区分"没动"和"被遮挡" | [JOPAT](https://arxiv.org/abs/2605.23856) |
| **Camera RoPE + 视锥掩码** | 免标定的多相机支持，只有落在视锥内的 token 参与注意力 | [WALL-WM](https://arxiv.org/abs/2606.01955) |
| **骨架渲染** | 已知运动学映射 + 空间对齐 | [OSCAR](https://arxiv.org/abs/2606.04463) |

JOPAT 的设计特别值得一提：纯外观 latent 在"物体没动"和"物体被遮挡了"两种情况下**完全相同**，但物理含义截然相反。加入可见性通道后，动作采样读到的是**对应关系级**的运动变量。这是一个很小的改动，却精确修补了外观表征的一个根本歧义。

## 7. 收敛度：这是全领域最不收敛的地方

**为什么动作表征难收敛**？因为它同时要满足四个互相拉扯的要求：

1. **表达力**：要能表达接触、力、形变 → 需要高维、连续
2. **空间对齐**：要与观测同坐标系 → 需要渲染成图，参数量大
3. **跨本体**：要本体无关 → 需要抽象，但抽象会丢信息
4. **可学习**：如果映射要学，就需要大量数据

骨架渲染在 2、3、4 上满分，在 1 上不及格。latent action 在 3、4 上部分满足，在 1、2 上不及格。**没有候选同时在四项上达标。**

我的判断：**短期（1–2 年）不会有统一答案**，会形成"任务相关的表征选择"：
- 刚体操作、跨本体 → 骨架
- 接触密集、需要力 → 点追踪 + 力/触觉通道
- 驾驶（动作是轨迹）→ 直接用轨迹，天然跨"本体"

---

## 8. 要点

1. 跨本体的关键是**映射 $T_e$ 已知还是需学**。骨架渲染的 $T_e$ 是解析的（正向运动学），这是它最大的优势（§1.2）。
2. 真实动力学含**本体特定残余**，共享接口表达不了它 → 接口损失是天花板（§3，Lab D7②：B 永远停在 2.004）。
3. **正确配方 = 共享接口预训练 + 目标本体残差微调**（配方 C），在 $n=10$ 时就把误差从 233 压到 0.427（§4.1③）。
4. 共享接口的价值与**目标本体数据稀缺程度**成正比；数据充足时收益会被接口损失抵消（§4.1④）。
5. 几何感知不只是动作表征，还包括几何监督、点追踪可见性、视锥掩码（§6）。
6. **这个方向没有赢家，短期不会收敛**（§7）。
